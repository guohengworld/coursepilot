## Q4：叉积计算点线距离（Recall=0.0）

### 现象
- Context Recall = **0.0** — 检索到的 UUID 集合与 ground truth 完全不重合
- Faithfulness = 0.273 — LLM 回答大部分陈述无法在上下文中找到依据
- Answer Relevancy = 1.0 — 回答仍然切题（LLM 用了自身知识）

### 根因分析
1. **KP 路径不精确**：ground truth 标注为 `微积分/第7章.../7.3 向量的数量积和向量积`，但"点到直线距离"的内容位于 7.4 节（空间直线），而非 7.3 节
2. **检索偏移**：向量检索召回了 7.3 节的内容（数量积/向量积定义），但 ground truth 期望的是 7.4 节中"叉积应用：点到直线距离公式"的具体段落
3. **UUID 层级错配**：ground truth 的 UUID 集指向了不存在于检索结果中的知识单元，说明标注时引用的单元与当前入库的单元不是同一批次

### 建议
- 重新审核 Q4 的 ground truth UUID，确保指向当前数据库中的正确单元
- 考虑将 kp_path 更新为 `7.4 空间直线及其方程` 或更细粒度

## Q7：第一/二类曲线积分对比（Precision=0.0, Faith=0.308）

### 现象
- Context Precision = **0.0** — 121 个检索到的 unit 中，LLM judge 判定 0 个与问题相关
- Faithfulness = 0.308 — 仅 30.8% 的 claims 能在上下文中找到依据
- Recall = 1.0 — ground truth UUID 全部命中

### 根因分析
1. **KP 路径太粗**：kp_path 为 `微积分/第10章 曲线积分和曲面积分`（章级别，无子节），KP 扩展拉取了整章 121+ 个 unit
2. **Context Precision 方法论缺陷**：per-unit judge 逐一判定 121 个 unit，每个只看前 500 字。教材中单个 unit 是碎片化的段落（如公式、中间推导），脱离上下文难以判定相关性 → 大量 false negative
3. **对比类问题需要跨节素材**：第一类曲线积分（10.1）和第二类曲线积分（10.2）分布在两个不同小节，检索无法精准定位对比性段落

### 建议
- 将 ground truth 的 kp_path 拆分到 10.1 和 10.2 子节
- 对比类问题考虑在 ground truth 中标注多个 kp_path
- Context Precision 应从 per-unit 改为 per-KP 级别（见性能审计报告）

## Q8：幂级数逐项可导可积（Faith=0.154, Relev=0.0）

### 现象
- Faithfulness = **0.154** — 13 个 claims 中仅 2 个被判定为 supported
- Answer Relevancy = **0.0** — LLM 判定回答完全不切题
- kp_path 标注为 `11.1 数项级数的概念和基本性质`，但"幂级数逐项可导/可积"是 **11.3 幂级数** 的内容

### 根因分析
1. **KP 路径完全错误**：幂级数的解析性质（逐项可导、逐项可积、收敛半径不变）属于 11.3 节，ground truth 标注为 11.1 节 → 检索到的内容根本不包含所需定理
2. **KPSplitter 章节分配问题**：第 11 章的知识单元大量集中在 11.1，11.2/11.3 的单元可能被错误归入 11.1
3. **Answer Relevancy = 0.0** 的原因：LLM 在缺乏相关上下文的情况下，可能生成了一段"数项级数收敛"的定义性回答，与"幂级数逐项可导"的题目完全不对口

### 建议
- **紧急修复 ground truth**：将 Q8 的 kp_path 改为 `微积分/第11章级 数/11.3 幂级数`
- 排查 KPSplitter 对第 11 章的分配质量，确认 11.2/11.3 的单元是否被正确归类

## Q11：二重vs三重积分（Precision=0.0, Faith=0.0）

### 现象
- Faithfulness = **0.0** — 15 个 claims 全部被判为 unsupported
- Context Precision = **0.0** — 73 个 unit 中 LLM judge 判定 0 个相关
- Recall = 1.0 — UUID 全部命中
- **最慢**：176.7s（11 题中最长）

### 根因分析
1. **三重积分内容缺失**：教材第 9 章重积分包含 9.1（概念与性质）、9.2（二重积分计算）、9.3（三重积分计算）、9.4（应用）。kp_path 仅标注到 9.1，无法获取三重积分的具体定义
2. **KP 扩展的量级问题**：9.1 下的 unit 数量巨大（73 个），per-unit judge 开销极高（176.7s），且碎片化段落逐个判定导致全 0
3. **对比类问题的固有难度**：需要同时覆盖二重和三重的定义，这两个内容在教材中是分离的

### 建议
- kp_path 应标注为 `9.1 重积分的概念和性质` + `9.3 三重积分的概念和计算`
- 对比类评估题应考虑多 KP 联合检索

## 系统性发现

### 1. Context Precision 指标失效
所有 11 道题的 Context Precision 都极低（0.0 ~ 0.059），这不是检索质量问题，而是 **per-unit judge 方法论缺陷**：
- 教材知识单元是碎片化段落（公式、中间步骤、图注），单独截取 500 字缺乏上下文
- LLM judge 无法从孤立的段落片段判断"是否有助于回答该问题"
- 实际有效的方法是 per-KP judge：将同一 KP 下的所有 unit 拼接后整体判断

### 2. KPSplitter 章节分配不均衡
- 第 11 章 4 道题中 3 道被分到 11.1，11.2/11.3 的单元可能未被正确拆分
- 第 9 章重积分中，9.1 承载了大部分单元，9.2/9.3/9.4 内容稀疏

### 3. Comparison 类型问题表现差
5 道 comparison 类型题中，3 道被标记为"严重"（Q7/Q8/Q11），Faithfulness 平均 0.307，显著低于 concept 类型的 0.857。原因是 comparison 需要跨 KP/跨节的素材，当前单 KP 检索无法覆盖。
