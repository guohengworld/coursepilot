## Bad Case 分析

### Q1 Faithfulness 1.0 → 0.083（退化）

级数收敛定义题，之前全量 unit 做 LLM 生成 → 12 claims 全 supported。当前 dense 粗排后上下文变窄，LLM 回答可能被裁剪的上下文"带偏"，导致 claims 无法在上下文中找到依据。CP=1.0 说明 KP 选对了，但 KP 内具体 unit 的选择不够好（语义粗排把定义性段落排到了后面）。

**结论**：dense 粗排对定义类问题（需要章首概念段落）可能不如全量覆盖。

### Q4 Recall 0.0 → 1.0（修复）

叉积距离计算题，初始版 ground truth UUID 完全不命中。当前版 Recall=1.0 说明全量 KP 加载 + dense 粗排覆盖到了相关 unit。但 CP=0.0 说明 judge 判定该 KP 不相关——可能是 kp_path 标注问题（内容在 7.4 但标注在 7.3）。

### Q8 Faith 0.154 → 1.0 / Relev 0.0 → 1.0（修复）

幂级数逐项可导题，初始版上下文完全不对（标注在 11.1 但内容在 11.3）。当前版全量 KP 加载覆盖到了正确的 unit，回答从答非所问变为完全忠实。

### Q11 Faith 0.0 → 0.944（修复）

二重vs三重积分对比题，初始版生成 15 claims 全 unsupported。当前版 dense 粗排把三重积分相关内容排进了 top-30 → cross-encoder 保留 → 上下文包含两方内容 → claims 可验证。

### CP 仍为 0.0 的题（Q2/Q4/Q7/Q8/Q9/Q11）

这些题 CP=0.0 并非检索失败，而是 KP 级 judge 的问题：当 KP 内容非常宽泛（如章级别 KP），即使包含相关 unit，整体判定仍可能被判 no。例如 Q7 的 KP 是 `第10章 曲线积分和曲面积分`（章级别），内容跨度太大，judge 难以判定"整章内容"是否相关。
